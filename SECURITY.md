# Security Policy

Report a vulnerability privately through the **Security** tab of this
repository using GitHub's private vulnerability reporting form. Do not
publish an unpatched vulnerability in a public issue or discussion.

Include the affected repository and commit, impact, reproduction steps, and
any safe mitigation you have identified. Maintainers will use the private
advisory to coordinate investigation and disclosure.

Report framework vulnerabilities against
[titanspan/framework](https://github.com/titanspan/framework).
