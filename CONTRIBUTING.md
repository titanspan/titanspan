# Contributing

This repository contains the official Titanspan application skeleton. Keep
changes focused on the starter's application structure, examples, and
developer experience.

Before proposing a change:

- Search existing issues and discussions.
- Explain the developer problem and the intended change.
- Include tests or documentation when they help verify the change.
- Run `make ci` and do not include credentials, private data, or unrelated
  edits.

Use this repository's Issues for skeleton-specific defects or requests. Send
framework defects and framework API proposals to
[titanspan/framework](https://github.com/titanspan/framework). Follow the
organization's [Code of Conduct](CODE_OF_CONDUCT.md) and the repository's
review guidance when opening a pull request.
